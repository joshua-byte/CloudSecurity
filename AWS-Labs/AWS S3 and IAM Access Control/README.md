# AWS S3 and IAM Access Control

## Overview
A hands-on lab exploring AWS S3 access control and IAM permissions through practical authorization tests.

## Objectives
- Test file uploads to S3 buckets.
- Investigate access-denied errors.
- Examine IAM roles and permissions.
- Understand S3 object-level permissions and ACL access.
- Explore access restrictions in Amazon EC2.

## Technologies Used
- Amazon S3
- AWS IAM
- Amazon EC2

## Key Concepts
- IAM policies and roles
- Least privilege
- S3 bucket and object permissions
- AWS authorization
