# Cloud Security Posture Management

## Overview
A hands-on lab exploring AWS security posture assessment and cloud resource inventory using ScoutSuite and CloudQuery.

## Objectives
- Assess AWS security configurations using ScoutSuite.
- Generate and review a cloud security assessment report.
- Configure CloudQuery to collect AWS resource data.
- Synchronize cloud inventory data into an SQLite database.
- Inspect AWS resources and review security-related information.

## Tools Used
- AWS
- ScoutSuite
- CloudQuery
- SQLite

## Key Concepts
- Cloud security posture assessment
- AWS resource inventory
- Security misconfiguration analysis
- Cloud data querying and synchronization
