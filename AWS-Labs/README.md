# AWS Cloud Security Labs

Hands-on labs exploring cloud security concepts and practical security configurations using Amazon Web Services (AWS).

## Labs

- AWS Security Posture Assessment using Prowler
- Cloud Security Posture Management using ScoutSuite and CloudQuery
- Data-at-Rest Encryption using AWS KMS
- Exploring IAM permissions, S3 access policies, and authorization failures

## Topics Covered

- AWS Identity and Access Management (IAM)
- Amazon S3 security and access control
- AWS KMS and encryption at rest
- Cloud security posture assessment
- AWS permissions and least privilege

## Disclaimer

These labs are for educational purposes and should be performed only in authorized environments.
