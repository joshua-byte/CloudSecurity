# AWS KMS — Data-at-Rest Encryption

## Overview
A hands-on lab exploring data-at-rest encryption in AWS using Key Management Service (KMS), Amazon S3, and Amazon EBS.

## Objectives
- Create and configure a customer-managed KMS key.
- Apply KMS encryption to an S3 object.
- Inspect KMS-related activity using AWS CloudTrail.
- Replace an unencrypted EC2 root volume with an encrypted EBS volume.
- Observe the impact of disabling a KMS key on encrypted resources.

## Tools Used
- AWS KMS
- Amazon S3
- Amazon EC2 and EBS
- AWS CloudTrail

## Key Concepts
- Encryption at rest
- Customer-managed KMS keys
- CloudTrail event analysis
- EBS volume encryption
- KMS key availability and resource access
